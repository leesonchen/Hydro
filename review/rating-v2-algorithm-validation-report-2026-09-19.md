## 一、本轮算法优化内容

| # | 优化 | 动机（来自抽查/校准的实测证据） | 实现 |
|---|---|---|---|
| 1 | **阻尼牛顿拟合** | 抽查发现 8/607 个拟合发散（pid 239 → -10934）：原始 Newton 步长在 p(1-p)≈0 区域无界 | `difficulty.ts`：步长钳制到 ±priorSd（600），收敛阈值 1e-6；仍不收敛 → `nonconverged` 不发布 |
| 2 | **预测层校准**（新增 `calibration.ts`） | 全局校准两端过自信：< -400 桶期望 4.3% vs 实际 5.1%，≥400 桶 95.5% vs 90.8% | 单一全局斜率 k 乘到 log-odds：`p = σ(k·a·(μ−D))`；**50% 点（μ=D）语义不变**，能力与难度保持同一标尺；对半切分仅隔离斜率拟合（半 A / 诊断半 B，确定性哈希）；难度仍来自全量结果 |
| 3 | **M15 残差诊断** | 计划验收矩阵要求"能力与通过显著反向 → 触发诊断而非只输出难度" | 逐题比较校准后期望解出率 vs 实际解出率，残差 ≥25pp（n≥20）列入 `m15Anomalies` |

设计边界说明：**没有**改动 Rating 模型（400 分制、Tanh、零和豁免均保持），也没有让难度反向影响能力——自洽通过"同一 50% 点标尺 + 同一预测函数"实现，而非相互拟合，避免计划 §3 禁止的反馈环。

## 二、本地环境验证（仓库测试，27/27 通过）

### 2.1 回归与单元测试

- 抽查缺陷回归：强制低迭代 → `nonconverged` 且无 SE ✓
- pid-239 形状回归：6 解出者（μ≈2037）+ 15 未解者（μ≈1869）现在收敛到 **d≈2071**（旧代码 -10934），落在数据邻域内 ✓
- 计划 M01~M05/M08/M12、A02~A04、C01~C04、D5 边界全部保持 ✓

### 2.2 合成数据真值恢复测试（自洽性的最硬验证）

设计：200 名虚拟学生（真实能力 ~N(1500, 250²)）、60 道虚拟题（真实难度 ~N(1650, 350²)）、25 轮比赛（每轮随机 30 人、60 题按真实能力生成胜负）、CF 风格名次更新 + 成熟度门控 + 首次观测去重，然后从提交流中恢复能力与难度。

| 指标 | 要求 | 实测 |
|---|---|---|
| 难度恢复（拟合 D vs 真实 D 皮尔逊相关） | > 0.85 | **通过** |
| 能力恢复（终态 μ vs 真实能力相关，≥5 场者） | > 0.75 | **0.973** |
| 校准斜率（真斜率=1 时） | 0.5 ~ 1.8 | 通过 |
| 校准后留出 logLoss | ≤ 原始 + 0.005 | 通过 |

结论：**算法能从纯比赛结果流中联合恢复能力与难度，二者在同一标尺上自洽**。测试过程中还排除了一个测试脚本自身的错误（对局结果误用当前评分而非真实能力生成，导致相关为 0——修正后恢复成立，这本身验证了"结果必须来自真实水平，评分才可能收敛到真实水平"）。

### 2.3 校准层单元测试

- 真斜率 0.6 的过自信数据：拟合 slope≈0.6 被恢复；校准后 logLoss 与分桶 MAD 均下降 ✓

### 3.3 M15 残差诊断（新增）

生产 607 题中 **0 题出现 ≥25pp 残差**——校准后没有任何题目表现出"能力与解出显著反向"，抽查时人工标注的弱区分度题（236/576）残差也在容忍带内。诊断将随每次回放自动输出。

### 3.4 回放稳定性

222 场处理 / 2 场冻结 / 0 场失败，与优化前完全一致；Rating、成就、综合投影数字不变（难度优化不回流能力模型，符合架构隔离要求）。

## 四、结论

1. **自洽性成立**：合成数据证明算法可从比赛结果流联合恢复能力与难度（0.973 / >0.85）；生产数据上预测层校准后期望/实际偏差全桶 ≤3.1pp。
2. **稳健性提升**：发散拟合 8 → 0，此前被放弃的题目获得合理估值；provisional 池 170 → 172。
3. **隔离性保持**：难度优化零回流能力模型；Rating/成就/投影逐字段不变。
4. 建议生产采用 `slope=0.8868` 作为展示层校准参数（每次回放自动重估，无需手工维护）。
