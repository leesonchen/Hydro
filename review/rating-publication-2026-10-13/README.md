# 系统评分算法切换（2026-10-13）

> 限域试用的数据口径、验证与部署操作请见 [TRIAL-PILOT.md](TRIAL-PILOT.md)。本报告保留首次开发时的验证快照，不代表之后代码已部署。

实现后的系统管理员入口为 `/manage/rating`，也可从“系统管理 → 评分算法”进入。页面需要系统管理权限和 sudo 验证。**本地容器尚未安装到新包，因此当前运行的网站还没有该入口。**

## 操作

1. 选择“旧版”或“V2 试用版”，填写试用域 ID（默认 `exam`）。
2. 点击“保存目标设置”。这里只保存目标配置；当前公开评分不变。
3. 在对应域点击“重算并应用”，然后刷新状态。完整批次校验成功后才生效。
4. 查看该域排行榜、首页榜单或用户个人页。V2 显示能力 Rating、参赛场次、成就 A、题目分 P、比赛分 C 和段位；未参赛者显示“未评级”。
5. 如需恢复上一批，点击“恢复上一次评分”。如需切回按当前数据计算的旧算法，选择旧版、保存，再手工重算该域。

每日任务只更新该域**已生效**的算法，不应用待手工重算的选择。回退也不改写目标配置，页面会显示仍待应用的选择。

## 规则与保存

- V2 采用 trial 的 P+C 公式和默认门槛：5 场定级、赛前至少5场才产生难度观测；未叠加旧版题解奖励或人工 RP 修正。
- trial 优先使用有效的 `submittedAt` 毫秒时间，历史记录缺失或无效时回退至 ObjectId 秒时间，并统计 `precisionFallbacks`。精确时间使用开始包含、结束排除的窗口；回退时间将窗口边界向下取整到秒。排序按有效提交时间和 ObjectId，OI 使用最后一次有效提交，ACM 使用第一次 AC 和非 CE 错误罚时。
- 个人计时使用参赛状态的 `startAt` 加 duration，并受个人 `endAt` 与整场结束时间限制；缺少或异常的开始事实明确排除并计数。
- 仅计入截止时已经结束的比赛。公开评分遵循结果可见性，隐藏的最佳状态可退回较早的可见记录。
- 合并有能力评级与有成就的用户，补齐 A=0 的比赛用户；用户隐藏、退出域或域删除会在读取/清理时生效。
- 每批结果独立保存到 `rating_publication_runs` / `rating_publication_users`。系统集合 `_id=rating.publication` 的配置与各域活动指针在同一文档，通过锁 token、活动版本和配置修订核验切换。
- 主任务校验完成后为 `ready`（计算完成，待发布）；活动指针、提交凭据和释放锁在同一次系统文档更新中完成，随后补齐 `complete`（已应用）状态。响应丢失或后续批次生效不影响原操作的成功凭据；成功回退显示“已回退”。
- 排队租约30分钟，执行租约90秒，每30秒续租，恢复扫描每15秒运行。发布前中断的任务在租约失效后作废，保留旧评分，管理员重新点击重算；正常恢复扫描下，最迟在最后一次续租后约105秒释放。数据库不可达时推迟恢复，不能把扫描失败当作任务已失效。
- 兼容旧版本把“计算完成、尚未发布”标为 `complete` 的情况：仅处理匹配原锁且未被活动/上一批引用的任务，缩短等待后作废。已发布历史快照不受影响。
- 计算失败、中断、并发、锁失效或手工配置变化不会替换当前公开批次。保留活动批次、上一批及各算法最近10批；超过30天且不被引用的旧批次可清理。
- 原 `domain.user` 的旧评分字段保留；标准页面及用户模型通过活动批次读取。直接查询旧字段的自定义插件需改用新的评分读取接口。

`asOf` 是提交截止时间，源数据仍读取当前有效判定；它不是全库事务快照或历史评测快照。旧最佳状态晚于截止时被排除，本轮未实现从历史记录恢复每次旧状态。跨域引用识别、全站共享评分、certified 正式切榜和 practice-rating 不属于本开关。

## 发布

使用 `./build-and-publish-dev.sh --packages hydrooj,ui-default`，仅发布至 `https://npm.leeson.top/` 的 dev 标签。开发版本保持 stable base：后端5.0.7、UI4.58.5。

目标是 `hydro` 容器。使用仓库 `install-dev-from-private-npm.sh update --packages hydrooj,ui-default` 更新，安装脚本内部执行 `pm2 restart hydrooj --update-env`；不重启 Docker 容器。

此前私有 registry 已发布后端 `5.0.7-dev.4` 与 UI `4.58.5-dev.6`，这些包不包含本轮修复。根据最新 `AGENTS.md`，本轮需要在修复、验证完成后获得新的单次发布授权，才可发布 `hydrooj,ui-default`；尚未执行新发布或更新容器。

浏览器验收脚本为 `tools/rating-publication-browser.cjs`，使用本地测试账号，并在成功或异常路径恢复原目标算法与域列表。若原活动批次存在，必须通过回退恢复其准确 runId，否则验收失败。若初始没有活动指针，管理 API 无法恢复指针不存在的状态，脚本仅回退至旧算法的 bootstrap 快照并在结果中标明限制；不保证该快照与重算前旧字段的分数逐用户一致。真实浏览器上线验收尚未执行。
