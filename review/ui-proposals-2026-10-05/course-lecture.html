循环与数位处理

这一课练习确定循环条件、更新循环变量，并检查边界。先用几组小数据推演，再运行程序核对结果。

从个位开始处理一个整数

用 n % 10 取个位，随后用 n /= 10 去掉已经处理的数位。

while (n > 0) {
    int digit = n % 10;
    // 使用 digit 完成当前这一步
    n /= 10;
}
