# UI 4.58.5-dev.4 Release note

Docker `hydro` 的实际 UI 从 `4.58.5-dev.2` 更新到 `4.58.5-dev.4`。后端仍为 `hydrooj 5.0.7-dev.2`；实际发布包对比（原始记录本地归档）确认后端文件及依赖无变化。开发发布保留 `4.58.5` 稳定基版本，只通过私有 npm 的 `dev` 标签发布。

- **修复普通课程保存失败。** 普通课程的「另存为模板」按钮不会再让页面初始化误填 `teachers`；普通 Update 正常保存，已有班级分配保留。
- **保留显式模板操作。** 点击「另存为模板」仍创建独立模板；编辑已有模板时通过专用隐藏标记识别状态，保留模板类别及无实例测评节点。
- **包含已有的时间选择器调整。** 课程页面直接加载 flatpickr；课程及测评时间控件统一使用本地日期时间格式，课程默认时间更新与控件保持同步，切换到测评类型时填入默认课时时间，章节重绘清理旧选择器。这些改动在本次修复前已存在于工作区，本包予以保留。
- **补充持续回归。** 新增 4 项基于真实模板、jQuery/JSDOM 与页面初始化的代码测试并接入 `npm test`；浏览器脚本补充真实题号输入、选题和失败诊断，模板脚本增加已有模板 Update 用例。

[浏览器回归报告](system-test-report.md)：13/13 通过，含课程编辑、门禁、测评成绩隐藏与解锁、模板保存与编辑、两个班级复制。原 MSG-02 的普通发信权限限制仍按测试前置条件不足处理，没有修改真实用户权限。此次未重新执行原发布全部 53 项用例。
