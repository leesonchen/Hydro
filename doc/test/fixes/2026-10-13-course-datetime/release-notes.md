# UI 4.58.5-dev.5 Release note

Docker `hydro` 的UI从`4.58.5-dev.4`升级至`4.58.5-dev.5`，后端仍为`5.0.7-dev.2`。[部署包对比](evidence/release-comparison.json)确认后端文件无变化；稳定基版本仍为`4.58.5`，仅通过私有npm的dev标签发布。

- **保留测评时间精度。** 编辑达标分数、监控或仅聚焦离开时间控件时，原始秒和毫秒保留；显式编辑一个时间边界只改变该边界。已开始测评可以正常保存分数和监控调整。
- **修复默认测评时间的时区偏移。** 按用户设置的时区解释默认课时，再转换成浏览器本地时间；课时计算覆盖夏令时变化。日期解析模块增加严格日历校验。
- **测评时间控件支持秒。** 保持课程时间字段的既有分钟格式。
- **纳入原生比赛设置布局。** 保留已合并的两列原生表单及文件侧栏，监控与封榜字段正常保存；回归测试改为检查控件和真实FormData，修复旧样式断言引发的CI失败。
- **扩充可复用验证。** 新增日期专项浏览器脚本，涵盖两个浏览器时区、已开始测评及独立边界编辑；导航驱动加强同地址提交等待。

验证：24项相关代码/构建测试、18项浏览器测试全部通过，临时测试数据清理完成。[完整报告](system-test-report.md)保留截图、原始驱动问题和最终重测来源。
