# 监控模式评审修复（2026-10-14）

对应 [review.md](review.md) 的两个 P1 缺陷及 ESLint 问题。本轮修改 UI、回归测试和测试命令，未改服务端监控策略。

## 修改

- 基础与高级编辑器通过保存归属交接草稿；隐藏表单不再保存旧值。离页同步读取当前 store，覆盖 debounce 已完成和未完成两种情况。
- 启动期间继续在基础表单输入、降级恢复和再次启动高级编辑器时，保留最新代码与语言；挂载失败也保留已从 IDB 恢复的草稿。
- 为聚焦的监控 Monaco 编辑器注册高于默认实现的粘贴命令处理器。菜单/命令通过监控脚本共用原生粘贴的来源校验，合法内部复制仍可粘贴；外部内容、读取失败或过期读取无法回落到 Monaco 原有的未校验读取逻辑。
- 命令处理器随编辑器销毁清理，其他编辑器保留默认行为。禁用剪贴板读取的浏览器仍可使用原生快捷键与现有 DOM 事件校验。
- 修复 JSX 字符串括号、单行语句数、缩进等 ESLint 问题。
- 新增实际执行模板与草稿桥接逻辑的回归，以及 Monaco 命令校验、权限失败、异步失效和生命周期测试；草稿测试已加入根 `yarn test`。
