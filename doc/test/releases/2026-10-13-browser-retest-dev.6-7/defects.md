# dev.6 / UI dev.7 浏览器复测缺陷

以下两项均在 Hydro `5.0.7-dev.7` / UI `4.58.5-dev.8` 修复并复测，见[根因与修复](../../fixes/2026-10-13-rating-queue-history/fix-report.md)及[发布复测报告](../2026-10-13-rating-queue-fix/system-test-report.md)。

## RATING-QUEUE：手工应用长期排队

复现：管理员在隔离临时域保存 V2 目标，点击“重算并应用”，刷新观察。第一次约 100 秒仍未完成，复核持续 queued；后一次复核被中断，不能算作完成的测试。原 PUB-04 记录失败。

PM2 online 不足以证明队列消费正常。最终查明索引初始化与一次性启动事件的注册存在时序竞态，导致任务处理器缺失。后续回归必须验证真实提交、worker 完成计算及生效指针，合成快照只用于验证显示行为。

## HISTORY-LAYOUT：时间修改记录文字重叠

复现：在原生比赛编辑页修改结束时间，确认保存，再展开时间修改记录。1500px 视口下标题与说明重叠 8px，提示段落上边距为 -8px；历史记录本身仍可读取，因此 TIME-05 功能断言通过，布局问题单独记录。

关键修复前后对照见[修复报告](../../fixes/2026-10-13-rating-queue-history/fix-report.md)。批量截图、排程与审计、重试和清理原始记录保存在本地归档。
