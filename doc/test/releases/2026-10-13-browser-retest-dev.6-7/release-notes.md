# 已部署版本的行为变更与复测范围

测试目标为 `hydro`，固定使用 `hydrooj@5.0.7-dev.6` 和 `@hydrooj/ui-default@4.58.5-dev.7`。对比安装快照为 `hydrooj@5.0.7-dev.5` / `@hydrooj/ui-default@4.58.5-dev.5`，本轮没有发布或升级。

| 已部署变更 | 浏览器验证 |
|---|---|
| 新增评分发布管理；保存目标与手工应用分开；支持恢复上次批次 | PUB-01～06；配置仅在测试期间临时调整，实际应用仅针对本轮临时域 |
| V2 试用榜单、个人详情、评分分项及当前可见成员排名 | RANK-01～03；独立显示快照明确标注，不能据此推断手工应用任务成功 |
| 练习评分管理员只读入口、默认关闭与参数权限边界 | PR-01～03 |
| 课堂测评时间精度、结束时间单独编辑、开始后元数据编辑、账号时区与浏览器时区不同 | DATE-01～04 |
| 原生比赛设置赛制切换、开启/关闭设置、学生编辑拒绝 | CSET-01、CON-01～03 |
| 时间修改确认与持久修改记录、重算失败展示和手工重试 | TIME-05、RECALC-01～02 |
| 课堂测评报名、监考、真实判题、赛中隐藏成绩、赛后课程解锁与删除/直接编辑限制 | ASM-01～05、MON-01～02、COUR-02、COUR-06 |

认证 CLI 的 CERT-01～02 为 C 级补充证据。安装器变更没有浏览器入口，本轮不重复安装器测试。

账号取自仓库根 `testuser.txt` 的本地管理员和学生标签；密码仅供进程内登录使用。既有 exam 数据保持只读，所有写入使用独立临时域。反馈和普通消息发送不属于本轮用例。
