# Hydro 开发版发布摘要

本次发布目标为：

- `hydrooj@5.0.7-dev.9`
- `@hydrooj/ui-default@4.58.5-dev.10`

相对上一版 `hydrooj@5.0.7-dev.8` / `@hydrooj/ui-default@4.58.5-dev.9`，本次主要收敛课堂测试功能：

- 统一使用父课程授权判断，覆盖课堂测试的 HTTP、WebSocket、代码下载、成绩板、题目访问和提交链路。
- 修复课堂测试普通记录列表的跨活动 WebSocket 推送风险，避免向学生泄露其他活动预运行记录或源代码。
- 修复课堂测试记录投影仍使用子比赛旧名单的问题，成绩板只投影当前父课程授权范围内的成员和分组。
- 修复课堂测试学生被错误识别为比赛维护者、认证流程因子比赛出席名单而阻塞，以及开始后题目/规则被修改的问题。
- 保持普通比赛的既有权限、记录和成绩板行为不变，并补充回归测试。
- 修复课堂测试排程日期、时间和时长的 UI 默认值兼容；课程侧栏统计入口文案恢复为“成绩表”。

V2 Rating 与教师课堂反馈相关代码随包发布，但本版本继续保持关闭：默认配置不启用 Rating 管理试用，也不启用课堂反馈入口；本次发布不代表这些功能已开放给生产用户。课堂测试是本次启用的主要功能。
