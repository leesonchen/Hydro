# Hydro `dev.2` 发布说明

对照的是两次实际活动包快照：previous 为 `hydrooj 5.0.7-dev.1`、`@hydrooj/ui-default 4.58.4-dev.41`，来自发布目录 `20261004051256`；current 为 `hydrooj 5.0.7-dev.2`、`@hydrooj/ui-default 4.58.5-dev.2`，来自发布目录 `20261012110535`。本次升级前备份目录为 `20261012110531`。包清单见 release-comparison.json（原始记录本地归档）。两份快照均没有可靠 `gitHead`，因此本说明按活动包 before/after 内容比较，不用日期推断 Git 基线。功能范围和建议浏览器用例见 [change-scope.json](change-scope.json)。本说明只记录源码确认的行为，不汇报浏览器用例结果。

## 新增

- **课堂反馈**：课程/作业活动可启用本地课堂反馈。教师可查看名册摘要、待处理项和历史，记录观察、撤回观察、标记处理完成或撤销处理；反馈状态冲突和权限受服务端校验。它是活动内的教学记录与跟进流程，不代表自动给学生评分。
- **课程测评节点**：课程结构可包含独立测评节点，并配置测评规则、参与者、题目和完成条件。课程前置条件可读取测评完成状态与成绩；课程/测评访问分别按教师、报名状态、章节门禁和活动规则判定。测评成绩在活动结束前可能保持隐藏，属于预期边界。
- **比赛监控页**：启用浏览器监控模式的比赛可查看监控事件与会话信息；采集受活动配置、参赛状态、速率限制和权限约束。
- **练习评分管理员试用页**：管理员可在课程或作业范围查看练习评分估计、评估日期和运行状态。该页面只提供只读试用，不替换公开比赛排名或既有 Rating。
- **题目/讲义内容反馈**：用户可从题目描述或课程讲义的标记/引用入口打开反馈对话框，选中文本可作为引用；提交后可从站内消息会话查看后续交流。收件规则为当前域 owner 和全站系统管理员（排除发送者）。反馈入口是页面内对话框，不存在独立的 Feedback 页面。

## 调整

- **课程结构及管理**：课程内容以结构节点管理，课程编辑/管理界面和章节呈现随之调整；课程模板复制、题目映射和时间范围处理可识别测评节点。课程详情增加测评时间、入口和个人成绩，并限制测评成绩榜仅教师可见；题目和讲义页面提供课堂反馈标记入口。课程管理响应会按权限投影内容，避免向无权用户泄露讲义字段。
- **课程测评准入和并发状态**：章节开放可把测评结果纳入前置条件。自动开放和课程进度更新会核对入课状态、测评版本及缓存快照，测评写入期间不给出可用于新授权的旧成绩；已有合法授权及教师手工决定按既定规则保留。普通比赛状态不参与课堂测评写入标记。
- **赛后练习**：比赛可提供赛后练习访问、题目和提交能力，并按参赛者/管理者权限控制记录与代码访问。它沿用比赛题目与练习记录关联，和比赛进行中的正式成绩、公开 Rating 分开处理。
- **团队参赛界面**：参赛入口支持选择个人或团队；团队页提供邀请成员及重命名操作。可用选项仍受比赛是否开放团队、团队成员与邀请码规则限制。
- **比赛设置页重构**：`contest_edit.html` 重排为“基础信息”“参赛与权限”“比赛过程”“成绩与公开”四组设置，开关增加说明，规则专属字段按当前比赛规则显示，编辑时回显已保存值。团队参赛开启后开关禁用，说明文字明确该选项不能关闭；团队参赛不能计入个人 Rating。比赛监控、赛后练习、成绩与展示设置也集中在相应分组。
- **评分试用认证边界**：试用页访问要求系统管理员权限，且目标域显式开启 `adminTrial`；普通教师、域管理员和学生不能凭旧的 `teacherTrial` 标记访问。`rating-v2-certify`、回放和练习评分脚本属于 CLI/运维入口，不是普通用户界面的认证功能，也不意味着自动发布评分。
- **消息交互**：消息列表和对话输入区会按当前对话类型及回复权限显示操作；不可回复的反馈对话呈只读状态，新建消息入口仅在允许发送时出现。
- **Markdown 与媒体渲染**：整篇讲义被 Markdown 外层围栏包住且包含标题和 Mermaid 围栏时，渲染阶段会解开外层包装；媒体渲染遇到缺少属性的 token 时以空值安全处理，避免直接对空属性调用字符串方法。普通代码围栏和存储内容保持原意。MarkdownIt 类型声明调整属于构建兼容，不单独列作用户功能或运行时修复。
- **样例与代码工具**：修正样例首行缩进识别；样例自测按钮通过 `getSampleInputCode` 取出已识别的题目样例输入，填入 Scratchpad 自测。它只运行现有判题自测流程，不新增任意代码执行入口。Monaco 对不支持格式化的语言不再显示可用格式化操作。
- **离线呈现**：头像请求失败时回退到站内默认图。小赖字体没有随本次 UI 包内置：生成样式文件明确为空，页面使用已安装字体或普通系统回退；Source Code Pro 仍随包提供本地 WOFF。屏蔽外网时页面可用性和没有外部小赖字体请求由浏览器用例检查。
- **用户设置和页面细节**：个人头像节点接入回退处理；域选择、课程/比赛侧栏、题目与提交页、记录页、搜索和讨论等页面随新入口及权限信息更新。`home_settings` 的源码变化主要是接入默认头像回退，不代表新增了一整套账户设置功能。

## 修复

- **课程题目门禁与测评并发修复已进入发布包**：活动包清单记录的 current SHA-256 与当前工作树中以下五个文件逐一匹配：`src/builtin/course-management/handler/course.ts`、`src/builtin/course-management/model/assessment.ts`、`src/handler/problem.ts`、`src/interface.ts`、`src/model/contest.ts`。这仅说明这五个文件的当前源码字节与 dev.2 包中对应文件一致；没有据此声称其他未核验文件或整个工作树一致。
- 课程题目门禁绕过要求适当的全局权限，或当前课程内有效的自管理权限；学生持有默认 SELF 权限本身不再越过章节禁止状态。合法章节编号 `0` 仍按有效编号处理。
- 测评状态写入会先后使课程状态失效并保留并发写入标记；中间读取不再使用过期测评成绩新增章节授权。授权同步检查入课状态身份、出勤、课程成绩、测评 revision 和缓存快照，避免并发覆盖新进度或创建意外状态。
- 反馈记录支持版本冲突检测、受控撤回/恢复以及与提交观察的关联，减少重复请求或身份切换造成的错误处理。
- 比赛记录可见性、代码查看和团队练习访问按参赛身份及管理权限检查；UI 会据此展示相应操作。
- Markdown 讲义外层围栏识别兼容 CRLF 与首尾空白，同时只处理符合标题和 Mermaid 条件的完整包装，避免误拆普通 Markdown 示例。

## 运维与启用边界

- `classroomFeedback` 域设置默认关闭；需在目标域显式启用后才开放本地课堂反馈入口。
- 评分试用需要系统管理员权限和域级 `adminTrial=true`，该开关默认关闭；认证、影子回放及重算脚本是显式 CLI 操作，不会因安装 dev 包自动执行。
- 包清单记录 `@hydrooj/framework` 从 `0.3.2-dev.1` 变为 `0.3.2`。hydrooj 对 `@hydrooj/common` 的声明由 `0.0.11-dev.1` 改为 `0.0.11`，但 comparison 记录的顶层实际 common 包前后均为 `0.0.11-dev.1`；声明版本不能误读为本次也升级了顶层 common 包。
- UI 包声明的 common 依赖从 `0.0.10` 改为 `0.0.11`。框架配置、依赖声明、编译产物哈希和静态资源指纹变化属于包/构建层，不作为独立用户功能列出。
- 分组/角色批量导入在 previous 包中已经存在；本次对应 handler 的变化只有遍历写法调整，没有用户可见功能变化，因此不列为新增或调整功能。
