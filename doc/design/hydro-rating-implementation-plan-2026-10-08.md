## 1. 目标、决策与当前基线

利用 Hydro 正常学习记录建立可回放的作答过程，分别产出学习成就、练习水平预估、比赛 Rating 和逐题统计难度。以未来独立测评检验模型，再按版本化政策迁移公开评分。Hydro 本地完成计算、权限、保存和发布。

## 2. 事实与样本契约

### 2.1 身份、资格与来源

题目键使用 `poolId + canonicalProblemId + problemRevision`，保留原始 `domainId/pid`、引用链和 `revisionStatus`。同 pid 跨域不得自动合并；同源副本仅在题面、评测数据和版本证据一致时归并。未知历史版本明确标记 unknown，不能用当前题面哈希替代历史。

来源保留 `FREE_PRACTICE / COURSE / HOMEWORK / CONTEST / UNKNOWN`。`practiceContest` 作为赛后学习上下文保留；归入自由练习时也必须携带来源活动引用。来源不赋予“独立完成”或可信度权重。

使用服务端记录、活动和仓库状态枚举。排除测试/服务账号、pretest/generate、作废/无效结果；pending 和系统故障作为缺失或待判断，正常 CE/WA/TLE 等保留为未完成过程。团队中的个人记录保留为学习事实，团队活动结果不用于个人能力或题目标定。

训练访问、教师诊断和公开展示分别授权。全站批处理权限不意味着教师拥有全站查询权限，也不允许将隐藏比赛的结果经分数变化提前公开。人工排除/撤销包含范围、理由、操作者、生效时间和影响模型，只修订模型输入，不删除判题事实。

### 2.2 作答过程与时间

普通学习以首个合格正式提交为 `t0`，窗口内同题课程、作业和自由练习记录可合并；有效 AC 为 1，到期且存在正常失败为 0，只有故障/pending 为缺失。7 天未结束的过程即使已经 AC 也不进入成熟训练集。无提交或未安排的普通练习不构造失败。

B 每个用户—规范题目版本仅使用首个合格基础过程。跨学习与比赛选择最早可确定机会，保留后续熟题记录供成就和诊断；R1 将资格时间、结束时间与稳定 ID 次序固化为样本规则并测试，不允许看结果后换优先顺序。重复 AC、重开任务或页面刷新均不重置 `t0`。

比赛使用实际参赛和个人合法窗口，复用正式 `RULES[].stat` 结算：OI 最后有效结果、IOI 最佳结果、StrictIOI 子任务合成。缺席不记失败，合法参赛且获得整套题才可把未完成题记 0。赛后提交进入学习成果，不能回流比赛。

分别保存提交时间、结果可知时间、重测结果引用和排除生效时间。历史回放只读取截止时已知结果；无法还原的内容报告为近似重建，优先补前瞻验证。

### 2.3 学习成就

成就从合法且可展示的原始结果抽取历史最高成果，AC=1，未 AC 的正部分分为 `0.5*clip(score/fullScore,0,1)`；非 AC 满分不推断为完全通过。按规范题目归并副本与实质同题，完整 AC 题数同样去重，不能用当前状态缓存冒充历史最高分。

成就与能力标定使用不同聚合目的；部分分保留在事实中，但不拆成二元模型的多次成功/失败。新统计难度不直接成为成就奖励权重。

## 3. 模型、尺度与评估

对照 A 修复现有比赛回放后生成版本独立的比赛 Rating 和比赛题目难度；按评分池隔离用户状态，冻结场次不推进定级。给定赛前能力的 `fitDifficulty()` 仅用于对应比赛估计，不把替换其输入当作实现 B。

主模型 B 使用成熟过程联合估计用户水平和题目难度，采用交替一维优化或等价稳定方法；记录目标函数、收敛、数据量、先验贡献和条件 SE。固定先验、固定窗口重复运行不得重复学习；不将上一后验设为新先验后再喂入同一历史数据。

所有结果带 `modelVersion`、`scaleId`、截止时间和状态；状态候选为 `unrated / prior_only / provisional / established / stale / excluded`，规则单独版本化。全正/全负或不收敛只保留诊断，不输出正常精确点值；条件 SE 不宣称涵盖联合参数、同班相关性和来源偏差的全部误差。近期证据不足不自动扣分，应保留最后有支持的估计和日期，或暂不估计。

全站遍历不合并各域训练集。域内不连通的分组也需分开诊断；跨域映射、共同用户/题目和版本化参考集合经 P03 验收后才连接到全站标尺。练习和比赛仍保留各自尺度语义，不因都使用千分制而直接相加。建立参考后不按每天全班均值重新归零，以免掩盖共同进步。

验证使用先切分再拟合的滚动时间留出；冻结样本窗口、映射、排除规则、题目参数、能力、校准及发布门槛。报告 L0 旧 RP、L1 近期不同题目成果、L2 最近可比测评、A、B；C 仅在验证期发现稳定来源偏差且连接可识别时增加，使用同样样本和切分。最终测试集不得用于选择 C 或调参。

普通 7 天完成概率与赛内独立完成概率分开。需要跨场景校准时只使用训练期测评，并在未来期冻结映射；新题没有预先难度则报告相对表现，不能先用未来答案标定再计算“事先预测”。

初始准入依据原文第 11.6 节：至少 3 次后续可比独立测评、2 个班、50 名不同学生；共同覆盖概率目标的 B−A Brier 差值置信上界 ≤ +0.01；相关性下降 0.03 为调查阈值，覆盖提升至少 10 个百分点为收益目标。按场次/班级合理簇报告不确定性，同时检查新增覆盖人群、教学误判和分组高估。只有同一目标可给出冻结概率时适用 Brier 条件。

这些门槛保留原文的含义，不把每个指标改成单次机械通过线。证据不足、指标不可比较或调查未解决时报告“尚无结论”。R5 可展示清楚标注的教师诊断；公开练习能力、K2 和教学资格结论必须等待相应验证。K1 的认证比赛链路独立验收，不以 B 覆盖收益代替比赛质量验证。

### 4.1 每日任务与活动指针

按域/池分批，每次固定输入截止和摘要；运行期间原始记录继续更新不改变本次冻结输入。使用数据库运行锁或 CAS 仲裁同一发布范围，同输入重放确定性，独立 runId 可追溯。

1. 生成不可变候选快照，分批写入新 runId；不得先删除活动结果。
2. 校验输入资格、映射/锚点、样本覆盖、收敛、输出计数、引用完整性和校验和；模型与政策必须已有对应发布资格。
3. 完整通过后按期望版本 CAS 切换活动指针，同时记录上一有效版本；读请求固定同一 runId，避免混读分量。
4. 写入或校验失败不切换。已切换后检测到候选完整性故障，按版本条件恢复上一有效指针并告警，防止回退覆盖后续成功版本。
5. 回退演练包括首版恢复 legacy 来源和后续恢复 previousRunId；保留历史，不依赖清空集合。

影子和教师活动版本可以每日更新；学生公开版本仅更新已启用的公开阶段。隐藏来源或锚定不足的范围不得自动提升公开资格；不能用其他域成功掩盖失败域，也不能在一次请求拼接不同发布版本。

### 4.2 公开迁移

K1 首次切换前保存旧 `rp/rpInfo/rank/level`、题解和 delta 分量、统计口径与榜单人群快照，生成新旧差异报告及公告。新公开页面直接使用新活动投影；旧字段是否物理回填需在 R0 查清插件读取方后决定，不将客户端仍读取旧值的路径当作迁移完成。

旧 `rp` 与 `calcLevel` 必须有已注册的域级模式保护，或与活动公开字段严格隔离，不能覆写新分数。切换和回退使用同一来源选择器及缓存失效规则，保留关闭新功能后恢复 legacy 路径的能力。题解/delta 按 P01 的最终决定处理，候选 P+C 公式不代表已批准删除它们。

先公开 K1 和清楚区分的统计详情。练习估计通过验证后可独立展示；在 P02 决定前仍使用 K1 综合榜，不将独立详情称为 K2 总榜已上线。正式 K2 若获准，新增独立政策版本，能力栏目改名并使用其自身成熟度规则。
