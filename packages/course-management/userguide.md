## 班级管理

### 1.1 进入班级管理页面

> 📷 **[截图位置：班级列表页面]**
> 
> 需要展示：
> - 左侧导航栏"班级管理"入口
> - 班级列表表格
> - "创建班级"按钮

1. 登录系统后，点击顶部导航栏的【管理】
2. 在左侧菜单中选择【班级管理】
3. 进入班级列表页面，可以看到当前域下的所有班级

### 1.2 创建新班级

> 📷 **[截图位置：创建班级表单]**
> 
> 需要展示：
> - 班级名称输入框
> - 教师选择器（UserSelectAutoComplete）
> - 学生选择器
> - 开始/结束日期时间选择
> - 归档复选框

1. 点击【创建班级】按钮
2. 填写班级信息：
   - **班级名称**：输入班级名称（如"2024春季高一班"）
   - **教师**：点击教师输入框，搜索并选择教师用户（可多选）
   - **学生**：点击学生输入框，搜索并选择学生用户（可多选）
   - **开始日期/时间**：设置班级开始时间
   - **结束日期/时间**：设置班级结束时间
   - **归档**：如需暂时隐藏该班级，可勾选归档
3. 点击【创建】按钮完成

### 1.3 编辑班级

> 📷 **[截图位置：编辑班级页面]**
> 
> 需要展示：
> - 已填充的班级信息
> - "分配的课程"区域
> - "添加课程"按钮

1. 在班级列表中找到需要编辑的班级
2. 点击班级名称或【编辑】链接
3. 修改需要调整的字段：
   - 可添加/删除教师和学生
   - 可修改时间范围
   - 可修改归档状态
4. 点击【更新】保存

**注意**：修改班级时间会自动同步更新该班级下所有课程的时间。

### 1.4 从模板复制课程到班级

> 📷 **[截图位置：添加课程对话框]**
> 
> 需要展示：
> - 课程模板选择下拉框
> - 可选模板列表

1. 进入班级编辑页面
2. 在"分配的课程"区域点击【添加课程】
3. 在弹出的对话框中选择要复制的课程模板
4. 点击【确定】
5. 系统会自动：
   - 复制课程结构和题目
   - 复制讲义内容
   - 复制相关文件
   - 将新课程分配给当前班级

## 课程模板管理

### 2.1 创建课程模板

> 📷 **[截图位置：创建课程页面（模板模式）]**
> 
> 需要展示：
> - "创建为模板"复选框
> - 模板分类输入框
> - 隐藏的"分配给班级"字段

课程模板是一种特殊的课程，用于快速复制到多个班级。

1. 进入【课程】页面，点击【创建课程】
2. 勾选【创建为模板】选项
3. 填写模板信息：
   - **模板分类**（可选）：如"高一物理"、"Python入门"等，用于分类管理
   - **课程标题**：模板的名称
   - **课程内容**：课程说明
4. 配置DAG章节结构（详见[章节与DAG配置](#章节与dag配置)）
5. 点击【创建】

**模板特点**：
- 模板自动分配给"TEACHERS"班级
- 不显示开始/结束时间设置
- 学生无法直接看到模板，只有教师可以查看和使用

### 2.2 管理课程模板

> 📷 **[截图位置：课程列表中的模板标签]**
> 
> 需要展示：
> - 标有"模板"标签的课程
> - 模板分类显示

1. 进入课程列表页面
2. 模板会显示【模板】标签和分类信息
3. 点击模板标题可以编辑模板内容
4. 编辑模板不会影响已复制到班级的课程

## 课程管理

### 3.1 创建普通课程

> 📷 **[截图位置：创建课程页面（普通模式）]**
> 
> 需要展示：
> - 未勾选"创建为模板"的状态
> - "分配给班级"选择器
> - 开始/结束时间设置

1. 进入【课程】页面，点击【创建课程】
2. **不勾选**【创建为模板】
3. 填写课程信息：
   - **课程标题**：课程名称
   - **课程内容**：课程描述
   - **分配给班级**：选择要分配的班级（只能选未归档的班级）
   - **开始时间**：课程开始时间
   - **结束时间**：课程结束时间
   - **维护者**：可添加其他教师作为维护者
4. 配置DAG章节结构
5. 点击【创建】

### 3.2 编辑课程基本信息

> 📷 **[截图位置：课程编辑页面]**

1. 进入课程详情页
2. 点击【编辑】按钮
3. 可以修改：
   - 标题和内容
   - 分配的班级
   - 时间范围
   - 维护者列表
   - DAG章节结构

### 3.3 删除课程

> ⚠️ **警告**：删除课程会同时删除所有相关数据，包括学生成绩！

1. 进入课程编辑页面
2. 点击【删除】按钮
3. 确认删除操作

## 章节与DAG配置

### 4.1 理解DAG结构

> 📷 **[截图位置：DAG编辑区域]**
> 
> 需要展示：
> - DAG JSON编辑框
> - 可视化编辑器（如果有）
> - 章节卡片列表

课程使用DAG（有向无环图）来组织章节，支持章节间的依赖关系。

**基本概念**：
- **章节（Node）**：课程的一个单元，包含题目和讲义
- **章节ID（_id）**：章节的唯一标识符（数字）
- **前置条件（requireNids）**：完成本章节需要先完成的其他章节ID列表
- **完成条件（completeCondition）**：判定章节完成的规则

### 4.2 DAG JSON格式

```json
[
  {
    "_id": 1,
    "title": "第一章：基础概念",
    "lecture": true,
    "pids": [1001, 1002, 1003],
    "completeCondition": {"type": "all"}
  },
  {
    "_id": 2,
    "title": "第二章：进阶应用",
    "lecture": true,
    "pids": [1004, 1005],
    "requireNids": [1],
    "completeCondition": {"type": "problem", "value": 1}
  },
  {
    "_id": 3,
    "title": "第三章：综合实践",
    "lecture": true,
    "pids": [1006, 1007, 1008, 1009],
    "requireNids": [1, 2],
    "completeCondition": {"type": "score", "value": 200}
  }
]
```

### 4.3 字段说明

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `_id` | number | 是 | 章节唯一ID，从1开始递增 |
| `title` | string | 是 | 章节标题 |
| `lecture` | boolean/string | 否 | 是否有讲义（true/false或讲义内容） |
| `pids` | number[] | 是 | 章节包含的题目ID列表 |
| `requireNids` | number[] | 否 | 前置章节ID列表 |
| `completeCondition` | object | 否 | 完成条件，默认`{type: "all"}` |

### 4.4 完成条件类型

| 类型 | 格式 | 说明 |
|------|------|------|
| `all` | `{"type": "all"}` | 完成所有题目 |
| `problem` | `{"type": "problem", "value": 3}` | 完成指定数量的题目 |
| `score` | `{"type": "score", "value": 100}` | 达到指定总分 |

### 4.5 配置步骤

> 📷 **[截图位置：DAG配置错误提示]**
> 
> 需要展示：
> - 错误的JSON格式提示
> - 验证错误信息

1. 在课程创建/编辑页面的【课程计划】区域
2. 可以直接编辑DAG JSON，或使用可视化编辑器
3. 点击【验证】检查配置是否正确
4. 常见问题：
   - 章节ID必须唯一
   - 所有题目ID必须存在
   - 前置条件中的章节ID必须已定义
   - 不能有循环依赖

## 讲义管理

### 5.1 编辑章节讲义

> 📷 **[截图位置：讲义编辑页面]**
> 
> 需要展示：
> - Markdown编辑器
> - 文件上传区域
> - 讲义预览

1. 进入课程详情页
2. 找到需要编辑讲义的章节
3. 点击章节标题旁的【讲义】链接或书本图标
4. 在编辑器中编写讲义内容（支持Markdown）
5. 可以上传相关文件（图片、PDF等）
6. 点击【保存】

### 5.2 上传课程文件

> 📷 **[截图位置：文件上传界面]**

1. 进入讲义编辑页面
2. 在文件管理区域点击【上传文件】
3. 选择要上传的文件
4. 等待上传完成
5. 上传的文件可以在讲义中引用

**文件限制**：
- 单个文件大小限制
- 总文件数量限制
- 具体限制由系统管理员配置

### 5.3 删除文件

1. 在讲义编辑页面的文件列表中
2. 找到要删除的文件
3. 点击【删除】按钮
4. 确认删除

> 
> 需要展示：
> - 成绩表格
> - 章节列
> - 总分和完成度

1. 进入课程详情页
2. 点击【成绩板】标签
3. 可以看到：
   - 所有学生的成绩列表
   - 每个章节的得分
   - 题目完成情况
   - 总进度百分比

### 6.2 导出成绩

> 📷 **[截图位置：成绩导出选项]**

1. 在成绩板页面，选择要导出的章节
2. 选择导出格式：
   - **CSV**：Excel可打开的表格格式
   - **HTML**：网页格式，包含样式
3. 点击【导出】下载文件

### 6.3 管理学生权限

> 📷 **[截图位置：课程管理页面]**
> 
> 需要展示：
> - 学生列表
> - 章节权限开关
> - "允许""禁止"按钮

1. 进入课程详情页
2. 点击【管理】按钮
3. 在学生列表中可以看到：
   - 每位学生的学习进度
   - 各章节的访问权限
4. 可以为特定学生：
   - **开放/关闭**整个课程访问
   - **开放/关闭**特定章节访问
   - **开放/关闭**讲义访问

### 6.4 批量权限操作

1. 在课程管理页面
2. 勾选多个学生（或使用全选）
3. 点击【批量允许】或【批量禁止】
4. 选择要操作的章节
5. 确认操作

## 常见问题

### Q1: 学生看不到课程怎么办？

**检查清单**：
1. 课程是否已分配给学生所在班级
2. 课程时间是否已开始
3. 学生是否已被添加到班级
4. 学生是否有`PERM_VIEW_HOMEWORK`权限
5. 课程是否被误删

### Q2: 学生无法访问某个章节？

**可能原因**：
1. 章节有前置条件，学生未完成前置章节
2. 教师手动禁止了该学生的章节访问
3. 课程时间未开始

**解决方法**：
1. 检查学生是否完成了前置章节
2. 在课程管理页面检查该学生的权限设置
3. 如有需要，手动为该学生开放章节权限

### Q3: 如何快速给多个班级分配相同课程？

**推荐流程**：
1. 创建课程模板
2. 在每个班级的编辑页面使用【添加课程】功能
3. 从模板复制课程到班级
4. 根据需要微调每个班级的课程时间

### Q4: DAG配置报错怎么办？

**常见错误**：
1. **"_id must be unique"** - 章节ID重复
2. **"required nid X not found"** - 前置条件引用了不存在的章节
3. **"problem not found"** - 题目ID不存在
4. **"circular dependency detected"** - 循环依赖

**解决方法**：
- 仔细检查JSON格式
- 确保所有ID正确
- 前置条件只能引用ID更小的章节（避免循环）

### Q5: 讲义中的图片无法显示？

**解决步骤**：
1. 确保图片已上传到课程文件
2. 检查图片引用路径是否正确
3. 图片格式应为JPEG/PNG/GIF等常用格式
4. 检查文件大小是否超过限制

## 附录

### 权限速查表

| 操作 | 所需权限 |
|------|----------|
| 查看课程列表 | `PERM_VIEW_HOMEWORK` |
| 创建课程 | `PERM_CREATE_HOMEWORK` |

- `Ctrl+S` - 保存讲义
- `Ctrl+B` - 粗体
- `Ctrl+I` - 斜体
