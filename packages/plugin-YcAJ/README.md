# 课程系统注意事项

学生不应有以下权限：

- PERM_CREATE_HOMEWORK （创建作业）
- PERM_EDIT_HOMEWORK （编辑作业）
- PERM_EDIT_HOMEWORK_SELF （编辑自己的作业）

班级教师需要有权限：

- PERM_CREATE_HOMEWORK （用于创建班级）

否则可能导致章节权限设置不生效。

应当在域中创建名为 `teachers` 的小组，将所有教师添加到组内，否则教师无法编辑其他教师创建的课程模板。
